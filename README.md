# handy-build

Personal build pipeline for [Handy](https://github.com/cjpais/Handy) by [CJ Pais](https://github.com/cjpais).

This repository contains **no Handy source code** — only a GitHub Actions workflow that checks out the official upstream repository at a pinned, reviewed tag (`v0.9.7`, commit `05e0aed`) and builds an unsigned macOS (Apple Silicon) binary for my own use.

- All credit for Handy goes to its author and contributors.

- If you just want to use Handy, download the official signed releases: https://github.com/cjpais/Handy/releases
